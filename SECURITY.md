# Security

Weekly Predictions stores forecasts and later review notes locally. It does not use AI to write predictions. Treat saved entries as plaintext and limit access through your Mac account. SHA-256 would not conceal a prediction or replace file permissions. Use made-up entries in reports.

The native app has an ad-hoc code signature. This lets the installer check whether its files changed. It does not prove who made the app. The build is not notarized. Use your Mac’s disk encryption to protect saved files.

Report security issues through [GitHub private vulnerability reporting](https://github.com/gmperkinsmba/weekly-predictions/security/advisories/new).
